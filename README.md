# Clone do YouTube - Página de Reprodução (Watch) 📺 

Este é o projeto prático do módulo de CSS, desenvolvido como parte dos desafios da **DIO** (Digital Innovation One). Para o curso **"Formação CSS Web Developer"**.

O objetivo principal deste desafio foi praticar clonando a interface de uma página do YouTube (especificamente a tela de reprodução de vídeo) utilizando **HTML5** e **CSS3**, com foco total dos conceitos de **Flexbox**.

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de todas as seções da página, cabeçalho, player de vídeo, barra de ações, comentários e recomendações.
* **CSS3:** Estilização visual completa, tema escuro (Dark Mode) inspirado no YouTube, gradientes nas miniaturas e estilização dos cards.
* **Flexbox:** Utilizado para criar o layout responsivo, alinhar elementos nas extremidades e organizar as colunas perfeitamente.
* **FontAwesome:** Biblioteca de ícones via CDN para os botões e menus.

---

## 🛠️ O que foi construído?

* **Cabeçalho (Header):** Fixo no topo, contendo o logotipo, barra de pesquisa personalizada e ícones de usuário.
* **Layout de Duas Colunas (Watch Layout):** 
  * **Coluna Esquerda:** Player de vídeo estático, título, barra de informações do canal (com botões de inscrição e ações de curtir/compartilhar) e uma seção de comentários emulada.
  * **Coluna Direita:** Barra de tags de filtro e lista de miniaturas de vídeos recomendados com títulos personalizados e estilizados.

---

## 💡 Aprendizados e Prática

Neste projeto, pude exercitar na prática conceitos fundamentais de desenvolvimento front-end:
* Organização de elementos usando `display: flex`.
* Alinhamento e distribuição de espaço com `justify-content` e `align-items`.
* Estruturação de layouts fluídos e limpos sem a necessidade de frameworks externos.
